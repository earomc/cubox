# cubox
A super fast Minecraft seed viewer based on [SteelMC's](https://github.com/Steel-Foundation/SteelMC/) world generator. SteelMC is a really cool project that you should check out! They basically did all the work ahahah. Huge thanks to them :)))

The name **cubox** is inspired by 'cubiomes' and the word oxidize (because of Rust, ha). And Minecraft is a game of cubes/boxes ... so it works in multiple ways I guess ...

# Goals
Right now you can only generate images with the CLI, but I want this to be a full seed viewer with its own GUI, similar to [amidst](https://github.com/toolbox4minecraft/amidst), [chunkbase](https://www.chunkbase.com/apps/seed-map) and [cubiomes viewer](https://github.com/Cubitect/cubiomes-viewer).
